# Life · OS 支持 / Support

Life · OS 是按「方向 → 专项 → 任务 → 子任务」组织事项的个人执行管理工具。免费使用，无广告、无内购。当前界面以中文为主。

## 开始使用

从首页新建方向，在方向内新建专项，再添加任务。日期可选；今天、未来 7 天、本月与本季度提供辅助视图。点任务可查看备注、进度与多层子任务。

## iCloud 同步

在各设备登录同一 Apple Account，并为 Life · OS 开启 iCloud。在 App 的「设置与同步」检查状态与最近上传、下载时间。首次安装后需要打开 App，联网并等待系统下载。未登录或离线时仍可本地记录，但其他设备不会立即收到。

空间不足时，请管理自己的 iCloud 储存空间。同步成功只说明最近一次系统同步完成；不保证另一台设备已下载，也不等于独立备份。更换账号、迁移版本或清理资料前，可在设置中导出完整备份。

## 与 Agent 协作

Mac 的本地接口由用户主动启用。需要另外构建开源仓库中的 `lifeos` CLI，并使用自己的 Agent 工具；App 不内置或销售 AI 服务。请先阅读 [Agent 协作](agent-workflow.md)、[构建说明](building.md)与[隐私政策](privacy.md)。不使用 Agent 也可以使用完整的任务管理功能。

## 问题反馈

通过 [GitHub Issues](https://github.com/Alex-cloud0413/lifeos-app/issues) 联系维护者 [Alex-cloud0413](https://github.com/Alex-cloud0413)。说明 App 版本、系统版本、复现步骤及期望结果即可。截图请遮挡私人信息；**不要上传任务备份、私人备注、Apple Account 凭据或签名文件**。

隐私问题可先以不含私人内容的说明提出，要求协助处理。开发者无法查看用户的私有 iCloud 数据；不会要求提供完整任务库来排查常规问题。

## English

Create a direction, add a project, then break work into tasks and nested subtasks. Dates are optional. iCloud sync requires the same Apple Account and iCloud enabled for Life · OS on all devices, plus available network and storage. Check Settings for recent upload/download activity. Local edits remain available offline. Sync is not an independent backup; export one before migration or cleanup.

The optional Mac Agent interface works with the separately built open-source CLI and an Agent of your choice. No AI service is included or required. For help, contact the maintainer through [GitHub Issues](https://github.com/Alex-cloud0413/lifeos-app/issues), including app/system versions and reproduction steps. Redact screenshots and never attach private tasks, backups or credentials. See the [Privacy Policy](privacy.md).
